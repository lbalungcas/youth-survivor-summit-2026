# Youth & Survivor Summit 2026

Official microsite for the **Youth & Survivor Summit 2026**, held on **16–17 November 2026** in **Manila, Philippines**. Convened as a **Global Ministerial Satellite Event** alongside the 2nd Global Ministerial Conference on Ending Violence Against Children.

---

## 🌟 Features & Design Variations

This repository provides two complete, mobile-responsive design variations:

- **Design 1 (`index.html` / `design-1.html`) — Classic & Clean**
  - Direct default landing page.
  - Uniform lime-green member badges with crisp black typography.
  - Three thematic Summit Pillars with solid black copy.
  - Authentic PNG logos for Brave Movement, Restless Development, and Global Youth-Led Movement.
  - Floating switcher to toggle to Design 2.

- **Design 2 (`design-2.html`) — Restless Development Brand Edition**
  - Authentic Restless brand visual identity (`#FF8F13` orange, `#050000` black, `#74C6CA` cyan).
  - Hard brutalist drop shadows (`4px 4px 0px #050000`) and stat cards.
  - Branded **Summit Schedule Coming Soon** card with preparatory highlights and registration CTAs.
  - 8 Organising Committee cards featuring country code tags (`ID`, `KE`, `NG`, `AU`, `GB`, `BR`).
  - Streamlined corporate charity footer with social channels.
  - Floating switcher to return to Design 1.
